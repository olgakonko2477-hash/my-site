# Игровая Академия знаний

Адаптивная библиотека обучающих браузерных игр по английскому языку для детей 7–12 лет. Проект работает без регистрации и серверной базы данных. Тема, звук, достижения и обезличенные игровые результаты могут сохраняться только в `localStorage` браузера.

## Требования и запуск

- Node.js актуальной LTS-версии (рекомендуется Node.js 20 или новее);
- npm, поставляемый вместе с Node.js.

```bash
npm install
npm run dev
```

Vite выведет локальный адрес сайта в терминале. Для production-сборки и её локальной проверки:

```bash
npm run build
npm run preview
```

Готовые статические файлы появятся в каталоге `dist/`. Публиковать нужно содержимое `dist/`, а не исходный код и не `node_modules`.

## Структура проекта

- `src/data/games.ts` — тип и единый каталог игр;
- `src/` — компоненты, маршруты, стили и игровая логика;
- `public/` — локальные публичные ресурсы, `favicon.svg`, `robots.txt`, `sitemap.xml`;
- `SECURITY_HEADERS.md` — рекомендуемые HTTP-заголовки и CSP;
- `DEPENDENCIES.md` — зависимости и лицензии.

## Как добавить новую игру

1. Создайте компонент или отдельную папку игры внутри `src/`. Все изображения, звуки, шрифты и иконки храните локально; не подключайте игру с внешнего сайта.
2. Добавьте внутренний маршрут игры в React Router. Для тяжёлого игрового модуля используйте динамический `import()`/`React.lazy`, чтобы он загружался только при открытии.
3. Добавьте объект в массив `games` в `src/data/games.ts`. Заполните все поля: `id`, `slug`, `title`, `description`, `cover`, `grades`, `gradeGroup`, `category`, `skills`, `topic`, `difficulty`, `duration`, `tasksCount`, `status`, `gamePath`, `isNew`, `isFeatured`.
4. Для готовой игры установите `status: 'available'` и укажите существующий внутренний путь в `gamePath`, например `/games/my-game`. Для незавершённой игры используйте `status: 'soon'` и пустой `gamePath`: карточка не должна вести на пустую страницу.
5. Не используйте `eval`, выполнение произвольной строки как кода, небезопасную вставку HTML и непроверенные параметры URL. Не сохраняйте имя, возраст, контакты или иные персональные данные ребёнка.
6. Проверьте карточку, прямой переход по URL игры, клавиатурное управление, мобильный экран, отключение звука и повторный запуск.

При подключении самостоятельной HTML/CSS/JavaScript-игры перенесите её код и ресурсы в проект и открывайте через внутренний маршрут или контролируемый локальный контейнер. Не загружайте игровые страницы с неизвестных доменов.

## Реквизиты и юридические тексты

Перед публикацией найдите по проекту и замените следующие заполнители реальными сведениями владельца:

- `[ФИО или наименование владельца]`;
- `[статус: ИП/самозанятый/ООО/физическое лицо]`;
- `[ИНН]`;
- `[ОГРНИП или ОГРН, если применимо]`;
- `[адрес]`;
- `[электронная почта]`;
- `[телефон]`;
- `[домен сайта]`.

Не публикуйте вымышленные реквизиты. Правила и политики являются заготовками и не гарантируют автоматического соответствия законодательству. До запуска их должен проверить компетентный специалист с учётом владельца, хостинга и фактической работы сайта.

## Домен и российский хостинг

Проект является статическим SPA и подходит для российского хостинга с поддержкой HTTPS и настройки перенаправлений.

1. Выполните `npm run build`.
2. Загрузите содержимое `dist/` в корневой каталог сайта на хостинге.
3. В панели регистратора направьте DNS-записи домена на хостинг по его инструкции. Изменение DNS может распространяться некоторое время.
4. Выпустите TLS-сертификат, включите HTTPS и постоянное перенаправление HTTP → HTTPS.
5. Настройте SPA rewrite: любой неизвестный путь, не соответствующий реальному файлу или каталогу, должен возвращать `/index.html`. Это необходимо для прямого открытия маршрутов React Router; настоящую страницу 404 показывает приложение.
6. Установите заголовки из `SECURITY_HEADERS.md` и проверьте, что CSP не блокирует локальные игровые ресурсы.
7. Замените `[домен сайта]` в юридических документах, canonical/OG-метаданных, `public/sitemap.xml` и `public/robots.txt`.
8. Не загружайте на публичный сервер `.git`, `.env`, исходные карты, резервные копии, журналы, конфигурации с секретами или другие служебные файлы.

Пример SPA rewrite для nginx (до общего обработчика ошибок):

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

Пример для Apache в `.htaccess` при включённом `mod_rewrite`:

```apache
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ index.html [L]
```

На хостинге с собственной панелью выберите аналог правила «fallback на `/index.html`». Не перенаправляйте запрос с кодом 301/302: сервер должен внутренне отдать `index.html`, сохранив исходный URL.

## Локальное хранение и приватность

Первая версия не требует cookies, регистрации, аналитики, рекламы, внешних шрифтов или CDN. `localStorage` допустим только для темы, звука, достижений и обезличенных результатов. Пользователь должен иметь возможность удалить результаты через интерфейс с подтверждением. Если состав хранилища или сетевых запросов изменится, до публикации обновите политики и проведите юридическую проверку.
