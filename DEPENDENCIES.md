# Сторонние зависимости и лицензии

Проект использует пакеты из npm. В `package.json` сейчас указаны плавающие версии `latest`; точные установленные версии фиксируются в `package-lock.json`, создаваемом командой `npm install`. Перед публикацией храните lock-файл в репозитории и собирайте проект через `npm ci`, чтобы сборка была воспроизводимой.

| Пакет | Назначение | Лицензия |
| --- | --- | --- |
| `react` | пользовательский интерфейс | MIT |
| `react-dom` | отображение React в браузере | MIT |
| `react-router-dom` | клиентская маршрутизация | MIT |
| `vite` | dev-сервер и production-сборка | MIT |
| `@vitejs/plugin-react` | поддержка React в Vite | MIT |
| `typescript` | проверка типов и компиляция TypeScript | Apache-2.0 |
| `@types/react` | определения типов React | MIT |
| `@types/react-dom` | определения типов React DOM | MIT |

Лицензии в таблице относятся к прямым зависимостям согласно сведениям соответствующих пакетов. У них есть транзитивные зависимости со своими лицензиями; итоговый состав необходимо получать из фактически установленного lock-файла, а не только из этой таблицы.

## Проверка перед выпуском

После установки зависимостей выполните:

```bash
npm audit
npm ls --all
npm run build
```

Для формирования полного лицензионного отчёта допустимо временно использовать проверенный инструмент, например `license-checker`, не добавляя его в production bundle:

```bash
npx license-checker --production --summary
npx license-checker --production
```

Использование `npx` может обращаться к npm и загружать пакет, поэтому выполняйте эту команду только в доверенной среде и проверяйте имя/версию инструмента. Сохраните полный отчёт для конкретной production-сборки и вручную проверьте неизвестные, нестандартные и copyleft-лицензии.

## Локальные ресурсы

Шрифты, изображения, звуки, иконки и игровые материалы также являются зависимостями с точки зрения авторского права, даже если не установлены через npm. Для каждого ресурса храните рядом или в реестре проекта:

- название и автора;
- источник и дату получения;
- название/текст лицензии;
- условия атрибуции;
- подтверждение права на коммерческое использование и изменение, если это требуется.

Не используйте персонажей, логотипы и иллюстрации третьих лиц без разрешения. CSS-формы, emoji и собственные материалы также нужно проверять с учётом платформы распространения и фактического источника.
